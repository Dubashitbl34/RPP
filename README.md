# РПП (режим и правильное питание)

## Описание:
Наш проект поможет вам составить меню на неделю. РПП — это персональный онлайн-диетолог.

## Стек технологий:
Проект полностью написан на языке Python. Для оформления сайта используется библиотека Streamlit. Все запросы обрабатываются локально моделью Qwen 2.5 (14B).

* Арсений — главный frontend-разработчик
* Илья — backend-разработчик
